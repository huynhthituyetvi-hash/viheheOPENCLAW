## 🚀 Hướng dẫn cài đặt và chạy

### Cách 1: Chạy bằng trình duyệt

1. Tải source code từ GitHub bằng cách chọn **Code → Download ZIP**.
2. Giải nén dự án.
3. Mở thư mục vừa giải nén.
4. Nhấp đúp vào file `index.html` để mở website bằng trình duyệt.

### Cách 2: Chạy bằng Visual Studio Code

1. Mở Visual Studio Code.
2. Chọn **File → Open Folder** và mở thư mục dự án.
3. Cài đặt tiện ích **Live Server** nếu chưa có.
4. Nhấp chuột phải vào `index.html`.
5. Chọn **Open with Live Server** để chạy website.

## 📤 Triển khai website bằng GitHub Pages

Để mọi người có thể truy cập website bằng đường link công khai:

1. Đưa các file `index.html`, `style.css`, `app.js` và `README.md` lên repository GitHub.
2. Mở repository trên GitHub.
3. Chọn **Settings → Pages**.
4. Trong mục **Build and deployment**, chọn:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
5. Nhấn **Save** và chờ GitHub triển khai website.
6. Mở đường dẫn được cung cấp trong mục Pages.
7. Cập nhật link demo ở đầu file README bằng URL thực tế.
